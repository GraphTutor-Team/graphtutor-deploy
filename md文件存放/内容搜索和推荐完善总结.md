## 📝 使用示例

### 搜索使用

```javascript
// 统一搜索
const result = await unifiedSearch({
  query: '操作系统',
  types: ['question', 'note', 'discussion'],
  page: 1,
  limit: 20,
  userId: 'user123',
});

// 快速搜索
const quickResult = await quickSearch('进程', {
  limit: 5,
  types: ['question'],
});
```

### 推荐使用

```javascript
// 统一推荐
const recommendations = await unifiedRecommendation({
  userId: 'user123',
  type: 'question',
  limit: 10,
});

// 基于错题推荐
const wrongBased = await recommendQuestionsFromWrong('user123', {
  limit: 10,
});
```

## 🔧 技术细节

### 相关性评分算法

- 完全匹配：+100分
- 单词匹配：每个匹配+10分
- 标题匹配：+50分
- 位置权重：开头匹配权重更高

### 推荐算法

1. **题目推荐**
   - 分析错题的知识点和标签
   - 匹配难度和类型
   - 考虑学习历史

2. **笔记推荐**
   - 基于标签匹配
   - 基于关联内容
   - 考虑公开性

3. **讨论推荐**
   - 基于热门度
   - 考虑点赞和回复数
