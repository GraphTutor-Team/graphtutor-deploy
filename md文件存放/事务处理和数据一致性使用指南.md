# 事务处理和数据一致性使用指南

**创建时间**: 2026-01-19

## 📋 概述

本项目已实现统一的事务处理和数据一致性保障机制，确保数据库操作的原子性和一致性。

## 🎯 核心功能

### 1. 事务处理工具

#### 1.1 基础事务执行

```javascript
import { withTransaction } from '../utils/transaction.js';

// 基本用法
const result = await withTransaction(async (session) => {
  const question = await Question.create([questionData], { session });
  await QuestionBank.findByIdAndUpdate(bankId, 
    { $inc: { questionCount: 1 } }, 
    { session }
  );
  return question[0];
});
```

#### 1.2 事务操作包装器

```javascript
import { transactional } from '../utils/transaction.js';

// 将函数包装为事务操作
const createQuestion = transactional(async (questionData, userId, session) => {
  const question = await Question.create([questionData], { session });
  // ... 其他操作
  return question[0];
});

// 使用
const question = await createQuestion(questionData, userId);
```

#### 1.3 批量操作事务

```javascript
import { batchTransaction } from '../utils/transaction.js';

const results = await batchTransaction([
  async (session) => await Question.create([q1], { session }),
  async (session) => await Question.create([q2], { session }),
  async (session) => await QuestionBank.findByIdAndUpdate(bankId, 
    { $inc: { questionCount: 2 } }, 
    { session }
  ),
]);
```

#### 1.4 事务超时控制

```javascript
import { transactionWithTimeout } from '../utils/transaction.js';

const result = await transactionWithTimeout(
  async (session) => {
    // 长时间运行的操作
  },
  30000 // 30秒超时
);
```

## 📝 使用示例

### 示例1: 创建题目API（使用事务）

```javascript
import express from 'express';
import { createQuestionWithBankUpdate } from '../utils/businessOperations.js';
import { asyncHandler, successResponse } from '../utils/errorHandler.js';
import { requireAuth } from '../middleware/auth.js';

const router = express.Router();

router.post('/',
  requireAuth,
  validateBody({ /* ... */ }),
  asyncHandler(async (req, res) => {
    const question = await createQuestionWithBankUpdate(
      req.body,
      req.user.id
    );
    
    res.status(201).json(successResponse(question, '题目创建成功', 201));
  })
);
```

### 示例2: 批量导入题目（使用事务）

```javascript
router.post('/batch',
  requireAuth,
  asyncHandler(async (req, res) => {
    const { questions, bankId } = req.body;
    
    // 为所有题目添加bankId
    const questionsData = questions.map(q => ({
      ...q,
      bankId,
    }));
    
    const createdQuestions = await batchCreateQuestionsWithBankUpdate(
      questionsData,
      req.user.id
    );
    
    res.json(successResponse(createdQuestions, '批量创建成功'));
  })
);
```

### 示例3: 自定义事务操作

```javascript
import { withTransaction } from '../utils/transaction.js';

router.post('/complex-operation',
  requireAuth,
  asyncHandler(async (req, res) => {
    const result = await withTransaction(async (session) => {
      // 步骤1: 创建题目
      const question = await Question.create([req.body], { session });
      
      // 步骤2: 更新题库
      await QuestionBank.findByIdAndUpdate(
        req.body.bankId,
        { $inc: { questionCount: 1 } },
        { session }
      );
      
      // 步骤3: 创建版本记录
      await QuestionVersion.create([{
        questionId: question[0]._id,
        version: 1,
        content: question[0].toObject(),
      }], { session });
      
      return question[0];
    });
    
    res.json(successResponse(result, '操作成功'));
  })
);
```

## 🔧 最佳实践

### 1. 何时使用事务

✅ **应该使用事务的场景**:
- 多个相关的数据库操作
- 需要保证原子性的操作
- 涉及计数更新的操作
- 数据一致性要求高的操作

❌ **不需要事务的场景**:
- 单个简单的查询操作
- 只读操作
- 独立的操作（无关联）

### 2. 事务性能考虑

- 事务会增加数据库锁定时间
- 避免在事务中执行长时间运行的操作
- 使用事务超时控制防止死锁
- 合理设置重试次数和延迟

### 3. 错误处理

```javascript
import { withTransaction } from '../utils/transaction.js';
import { NotFoundError } from '../utils/errorHandler.js';

try {
  await withTransaction(async (session) => {
    // 操作
  });
} catch (err) {
  // 事务会自动回滚
  // 处理错误
}
```

### 4. 嵌套事务

MongoDB不支持真正的嵌套事务，但可以使用同一个session：

```javascript
import { nestedTransaction } from '../utils/transaction.js';

await nestedTransaction(async (parentSession) => {
  // 在同一个session中执行
  await nestedTransaction(async (session) => {
    // 使用同一个session
  }, parentSession);
});
```
