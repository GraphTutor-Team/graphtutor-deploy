# 内容搜索和推荐使用指南

**创建时间**: 2026-01-19

## 📋 概述

本项目已实现统一的内容搜索和智能推荐系统，支持题目、笔记、讨论的统一搜索和个性化推荐。

## 🎯 核心功能

### 1. 统一搜索服务

#### 1.1 基础搜索


## 📝 API使用示例

### 统一搜索API

#### GET /api/v3/search

```bash
# 基本搜索
GET /api/v3/search?q=操作系统&types=question,note&page=1&limit=20

# 带筛选的搜索
GET /api/v3/search?q=进程&difficulty=3&subjectCode=CS&tags=操作系统,进程

# 搜索特定类型
GET /api/v3/search?q=学习笔记&types=note&page=1&limit=10
```

## 🔧 前端使用示例

### React组件示例

```javascript
import { useState, useEffect } from 'react';
import api from '../api/api';

function SearchComponent() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);
  const [loading, setLoading] = useState(false);

  const handleSearch = async () => {
    setLoading(true);
    try {
      const response = await api.get('/v3/search', {
        params: {
          q: query,
          types: 'question,note,discussion',
          page: 1,
          limit: 20,
        },
      });
      setResults(response.data.data);
    } catch (err) {
      console.error('搜索失败:', err);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div>
      <input
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        onKeyPress={(e) => e.key === 'Enter' && handleSearch()}
      />
      <button onClick={handleSearch}>搜索</button>
      {loading && <div>搜索中...</div>}
      <div>
        {results.map((item) => (
          <div key={item._id}>
            <h3>{item.title || item.content}</h3>
            <p>类型: {item._searchType}</p>
          </div>
        ))}
      </div>
    </div>
  );
}
```

### 推荐组件示例

```javascript
import { useState, useEffect } from 'react';
import api from '../api/api';

function RecommendationComponent({ userId }) {
  const [recommendations, setRecommendations] = useState([]);

  useEffect(() => {
    const loadRecommendations = async () => {
      try {
        const response = await api.get('/v3/search/recommend', {
          params: {
            type: 'question',
            limit: 10,
          },
        });
        setRecommendations(response.data.data);
      } catch (err) {
        console.error('加载推荐失败:', err);
      }
    };

    if (userId) {
      loadRecommendations();
    }
  }, [userId]);

  return (
    <div>
      <h2>为您推荐</h2>
      {recommendations.map((item) => (
        <div key={item._id}>
          <h3>{item.content}</h3>
          <p>难度: {item.difficulty}</p>
        </div>
      ))}
    </div>
  );
}
```

## 📊 搜索特性

### 相关性评分

搜索结果按相关性评分排序，评分考虑：
- 完全匹配：+100分
- 单词匹配：每个匹配+10分
- 标题匹配：+50分
- 位置权重：开头匹配权重更高

### 多类型搜索

支持同时搜索多种内容类型：
- `question` - 题目
- `note` - 笔记
- `discussion` - 讨论

### 高级筛选

支持多种筛选条件：
- 难度筛选（1-5）
- 学科代码筛选
- 题库筛选
- 标签筛选
- 类型筛选
- 状态筛选（讨论是否已解决）

## 🎯 推荐算法

### 题目推荐

1. **基于错题推荐**
   - 分析用户错题的知识点和标签
   - 推荐相同知识点或标签的题目
   - 考虑难度匹配

2. **基于学习历史推荐**
   - 分析用户最近学习的内容
   - 推荐相同知识点的其他题目

3. **热门推荐**
   - 推荐热门题目（基于创建时间）

### 笔记推荐

1. **相关笔记推荐**
   - 基于标签匹配
   - 基于类型匹配
   - 基于关联题目或知识点

2. **热门笔记推荐**
   - 基于浏览次数和更新时间

### 讨论推荐

1. **热门讨论推荐**
   - 基于点赞数和回复数
   - 基于创建时间

## 🚀 最佳实践

### 1. 搜索性能优化

- 使用快速搜索获取少量结果
- 使用分页避免一次加载过多数据
- 合理设置limit参数

### 2. 推荐策略

- 优先使用基于用户行为的推荐
- 结合热门推荐作为补充
- 定期更新推荐结果

### 3. 用户体验

- 提供实时搜索建议
- 显示搜索结果数量
- 提供高级筛选选项
- 显示推荐理由
