## 🚀 快速开始继续工作

### 1. 检查项目环境

```bash
# 检查Node.js版本（需要 >= 16.0.0）
node --version

# 检查MongoDB是否运行
# Windows: net start MongoDB
# Linux/Mac: sudo systemctl status mongod
```

### 2. 安装依赖（如果需要）

```bash
# 安装所有依赖
npm run setup
```

### 3. 启动项目

```bash
# 终端1: 启动后端
npm run server

# 终端2: 启动前端
npm run client
```

### 4. 访问应用

- 前端：http://localhost:5173
- 后端：http://localhost:5000
