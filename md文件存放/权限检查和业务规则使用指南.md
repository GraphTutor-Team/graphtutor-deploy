# 权限检查和业务规则使用指南

**创建时间**: 2026-01-19

## 📋 概述

本项目已实现统一的权限检查和业务规则验证系统，确保数据安全和业务逻辑正确性。

## 🎯 核心功能

### 1. 权限检查服务 (PermissionService)

#### 1.1 基础权限检查

```javascript
import PermissionService, { checkPermission } from '../services/permissionService.js';

// 检查用户是否是资源所有者
const isOwner = PermissionService.isOwner(userId, resource, ['ownerId', 'createdBy']);

// 检查用户是否是管理员
const isAdmin = PermissionService.isAdmin(user);

// 检查用户是否具有指定角色
const hasRole = PermissionService.hasRole(user, ['admin', 'teacher']);
```

#### 1.2 资源权限检查

```javascript
// 检查是否可以查看题库
const result = await PermissionService.canViewBank(user, bank);
if (result.allowed) {
  // 允许访问
} else {
  // 拒绝访问，原因在 result.reason
}

// 检查是否可以修改题库
const result = await PermissionService.canModifyBank(user, bank);

// 检查是否可以删除题库
const result = await PermissionService.canDeleteBank(user, bank);

// 检查是否可以修改题目
const result = await PermissionService.canModifyQuestion(user, question);

// 检查是否可以查看/修改笔记
const viewResult = PermissionService.canViewNote(user, note);
const modifyResult = PermissionService.canModifyNote(user, note);

// 检查是否可以查看/修改讨论
const viewResult = PermissionService.canViewDiscussion(user, discussion);
const modifyResult = PermissionService.canModifyDiscussion(user, discussion);
```

#### 1.3 便捷函数

```javascript
import { checkPermission, hasPermission } from '../services/permissionService.js';

// 检查权限并抛出错误（如果失败）
const result = await PermissionService.canModifyBank(user, bank);
checkPermission(result); // 如果失败会抛出ForbiddenError

// 检查权限并返回布尔值
const allowed = hasPermission(result);
```

### 2. 权限检查中间件

#### 2.1 预定义中间件

```javascript
import {
  checkViewBank,
  checkModifyBank,
  checkDeleteBank,
  checkModifyQuestion,
  checkModifyNote,
  checkModifyDiscussion,
} from '../middleware/checkPermission.js';

// 查看题库
router.get('/banks/:id',
  requireAuth,
  checkViewBank, // 自动检查权限并挂载req.bank
  handler
);

// 修改题库
router.put('/banks/:id',
  requireAuth,
  checkModifyBank, // 自动检查权限并挂载req.bank
  handler
);

// 删除题库
router.delete('/banks/:id',
  requireAuth,
  checkDeleteBank, // 自动检查权限并挂载req.bank
  handler
);
```

#### 2.2 自定义权限检查中间件

```javascript
import { createPermissionCheck } from '../middleware/checkPermission.js';

// 创建自定义权限检查中间件
const checkCustomResource = createPermissionCheck(
  async (user, resource) => {
    // 自定义权限检查逻辑
    if (user.role === 'admin') {
      return PermissionResult.allow();
    }
    if (PermissionService.isOwner(user.id, resource)) {
      return PermissionResult.allow();
    }
    return PermissionResult.deny('无权访问');
  },
  async (req) => {
    // 加载资源
    const Resource = (await import('../models/Resource.js')).default;
    return await Resource.findById(req.params.id).lean();
  }
);

router.get('/resources/:id',
  requireAuth,
  checkCustomResource,
  handler
);
```

### 3. 业务规则验证 (BusinessRules)

#### 3.1 题目相关验证

```javascript
import BusinessRules from '../services/businessRules.js';

// 验证题目选项
BusinessRules.validateQuestionOptions(options, 2, 10); // 最少2个，最多10个

// 验证答案索引
BusinessRules.validateAnswerIndex(answerIndex, options);

// 验证难度
BusinessRules.validateDifficulty(difficulty, 1, 5);

// 验证标签
BusinessRules.validateTags(tags, 10, 20); // 最多10个标签，每个最多20字符
```

#### 3.2 题库相关验证

```javascript
// 验证题库名称唯一性
await BusinessRules.validateBankNameUnique(name, ownerId, excludeId);

// 验证题库是否可以删除
BusinessRules.validateBankDeletion(bank);

// 验证题目是否可以删除
BusinessRules.validateQuestionDeletion(question, bank);
```

#### 3.3 通用验证

```javascript
// 验证分页参数
BusinessRules.validatePagination(page, limit, maxLimit);

// 验证排序字段
BusinessRules.validateSortField(sortBy, ['createdAt', 'updatedAt', 'name']);

// 验证日期范围
BusinessRules.validateDateRange(startDate, endDate);

// 验证文件大小
BusinessRules.validateFileSize(fileSize, 10 * 1024 * 1024); // 10MB

// 验证文件类型
BusinessRules.validateFileType(mimeType, ['image/jpeg', 'image/png']);
```

## 📝 使用示例

### 示例1: 创建题目（业务规则验证）

```javascript
router.post('/questions',
  requireAuth,
  asyncHandler(async (req, res) => {
    const { content, options, answerIndex, difficulty, tags } = req.body;

    // 业务规则验证
    BusinessRules.validateQuestionOptions(options, 2, 10);
    BusinessRules.validateAnswerIndex(answerIndex, options);
    BusinessRules.validateDifficulty(difficulty, 1, 5);
    if (tags) {
      BusinessRules.validateTags(tags, 10, 20);
    }

    // 创建题目
    const question = await Question.create({
      content,
      options,
      answerIndex,
      difficulty,
      tags,
      creatorId: req.user.id,
    });

    res.json(successResponse(question, '创建成功'));
  })
);
```

### 示例2: 修改题库（权限检查 + 业务规则验证）

```javascript
router.put('/banks/:id',
  requireAuth,
  checkModifyBank, // 权限检查
  asyncHandler(async (req, res) => {
    const { name, description } = req.body;

    // 业务规则验证
    await BusinessRules.validateBankNameUnique(
      name,
      req.user.id,
      req.params.id
    );

    // 更新题库
    const bank = await QuestionBank.findByIdAndUpdate(
      req.params.id,
      { name, description },
      { new: true }
    );

    res.json(successResponse(bank, '更新成功'));
  })
);
```

### 示例3: 删除题库（权限检查 + 业务规则验证）

```javascript
router.delete('/banks/:id',
  requireAuth,
  checkDeleteBank, // 权限检查
  asyncHandler(async (req, res) => {
    // 业务规则验证
    BusinessRules.validateBankDeletion(req.bank);

    await QuestionBank.findByIdAndDelete(req.params.id);
    res.json(successResponse(null, '删除成功'));
  })
);
```

### 示例4: 在服务层使用权限检查

```javascript
import PermissionService, { checkPermission } from '../services/permissionService.js';

async function updateQuestion(questionId, data, user) {
  const question = await Question.findById(questionId).lean();
  
  // 检查权限
  const result = await PermissionService.canModifyQuestion(user, question);
  checkPermission(result); // 如果失败会抛出ForbiddenError

  // 业务规则验证
  if (data.options) {
    BusinessRules.validateQuestionOptions(data.options);
  }

  // 更新题目
  return await Question.findByIdAndUpdate(questionId, data, { new: true });
}
```

### 示例5: 分页查询（业务规则验证）

```javascript
router.get('/questions',
  requireAuth,
  asyncHandler(async (req, res) => {
    const { page = 1, limit = 20, sortBy = 'createdAt' } = req.query;

    // 业务规则验证
    BusinessRules.validatePagination(parseInt(page), parseInt(limit), 100);
    BusinessRules.validateSortField(sortBy, [
      'createdAt',
      'updatedAt',
      'difficulty',
      'content',
    ]);

    const questions = await Question.find({})
      .sort({ [sortBy]: -1 })
      .skip((page - 1) * limit)
      .limit(limit);

    res.json(successResponse(questions));
  })
);
```

## 🔒 权限规则说明

### 题库权限

- **查看权限**:
  - 管理员：可以查看所有题库
  - 官方题库：所有用户都可以查看
  - 小组题库：群组成员可以查看
  - 个人公开题库：所有用户都可以查看
  - 个人私有题库：只有创建者和管理者可以查看

- **修改权限**:
  - 管理员：可以修改所有非官方题库
  - 官方题库：只有管理员可以修改
  - 小组题库：群组老师可以修改
  - 个人题库：创建者和管理者可以修改

- **删除权限**:
  - 管理员：可以删除所有非官方题库
  - 官方题库：只有管理员可以删除
  - 小组题库：群组老师可以删除
  - 个人题库：只有创建者可以删除（且没有其他管理者）

### 题目权限

- **修改权限**:
  - 管理员：可以修改所有题目
  - 创建者：可以修改自己创建的题目
  - 题库关联：根据题库权限决定

### 笔记和讨论权限

- **查看权限**:
  - 管理员：可以查看所有内容
  - 公开内容：所有用户都可以查看
  - 私有内容：只有创建者可以查看

- **修改权限**:
  - 管理员：可以修改所有内容
  - 创建者：可以修改自己创建的内容

## ⚠️ 注意事项

### 1. 权限检查顺序

- 先检查用户是否认证
- 再检查资源是否存在
- 最后检查权限

### 2. 业务规则验证

- 在创建/更新数据前进行验证
- 验证失败会抛出BadRequestError或ConflictError
- 使用try-catch捕获错误

### 3. 错误处理

```javascript
try {
  BusinessRules.validateQuestionOptions(options);
} catch (error) {
  if (error instanceof BadRequestError) {
    return res.status(400).json({ message: error.message });
  }
  throw error;
}
```
