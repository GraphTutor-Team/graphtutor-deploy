# 文档存放目录

此文件夹用于存放项目的所有Markdown文档文件，便于统一管理和查找。

## 📁 文档分类

### 项目状态
- `项目当前状态.md` - 项目当前状态总结

### 功能文档
- 功能更新记录
- 功能说明文档
- 新功能介绍

### 测试文档
- 测试清单
- 测试报告
- 测试指南

### 修复记录
- 错误修复记录
- Bug修复记录
- 问题解决记录

### 部署文档
- 部署指南
- 环境配置
- 启动说明

## 📝 文档整理说明

所有项目根目录下的 `.md` 文件（除了 `README.md`）都应该移动到此文件夹中，以保持项目根目录的整洁。

## 🔍 查找文档

使用文件搜索功能可以快速找到需要的文档。
