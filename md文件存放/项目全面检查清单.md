## 🐛 登录500错误排查步骤

### 步骤1: 查看服务器控制台日志

**关键日志位置**:
- `[LOGIN]` 开头的日志
- `数据库查询失败` 错误
- `JWT签名失败` 错误
- `login error` 错误

### 步骤2: 检查数据库连接

```bash
# 检查MongoDB是否运行
# Windows PowerShell
Get-Service -Name MongoDB*

# 或检查端口
netstat -ano | findstr :27017
```

### 步骤3: 测试数据库连接

在服务器控制台查看是否有：
```
MongoDB connected successfully
```

如果没有，检查：
1. MongoDB服务是否启动
2. `MONGODB_URI` 是否正确
3. 防火墙是否阻止连接

### 步骤4: 检查环境变量

确保 `server/.env` 文件存在：

```env
MONGODB_URI=mongodb://127.0.0.1:27017/graphtutor
JWT_SECRET=your-secret-key-here
PORT=5000
NODE_ENV=development
```

### 步骤5: 检查中间件顺序

确保 `server/src/app.js` 中顺序正确：

```javascript
1. securityHeaders
2. cors
3. express.json()
4. responseTimeLogger
5. morgan
6. apiRateLimiter (限流)
7. strictRateLimiter (登录限流)
8. 路由
9. handleError (错误处理)
10. 404处理
```

## ⚠️ 常见错误模式

### 模式1: 数据库连接失败
**错误**: `MongoServerError` 或 `MongooseError`
**解决**: 检查MongoDB服务状态和连接字符串

### 模式2: JWT错误
**错误**: `JsonWebTokenError` 或 `TokenExpiredError`
**解决**: 检查 `JWT_SECRET` 环境变量

### 模式3: 中间件错误
**错误**: `TypeError: Cannot read property 'xxx' of undefined`
**解决**: 检查中间件顺序和req对象

### 模式4: 导入错误
**错误**: `Cannot find module` 或 `does not provide an export`
**解决**: 检查导入路径和导出语句
