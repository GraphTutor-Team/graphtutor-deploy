## 🚀 启动项目

### 安装依赖
```bash
npm run setup
```

### 启动开发服务器
```bash
# 终端1: 启动后端
npm run server

# 终端2: 启动前端
npm run client
```

### 访问地址
- 前端：http://localhost:5173
- 后端：http://localhost:5000
