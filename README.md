# GraphTutor V3.0 - 多角色与学科分类系统

## 🚀 快速开始

### 安装依赖
```bash
# 安装所有依赖（根目录、客户端、服务端）
npm run setup
```

### 启动项目
```bash
# 方式1: 分别启动（推荐）
# 终端1: 启动后端
npm run server

# 终端2: 启动前端
npm run client

# 方式2: 使用启动脚本（Windows）
start.bat  # 或 start.ps1

# 方式3: 使用启动脚本（Linux/Mac）
./start.sh
```

**访问地址**:
- 前端：http://localhost:5173  
- 后端：http://localhost:5000

## 📚 V3.0 新功能

### 核心功能
- ✅ **多角色系统**: 学生、出题负责人、管理员
- ✅ **学科分类**: 层级化学科分类管理
- ✅ **题库管理**: 增强的题库管理功能
- ✅ **题目管理**: 完整的题目CRUD和版本控制
- ✅ **AI集成**: OpenAI API深度集成
- ✅ **导出/导入**: 支持JSON和CSV格式
- ✅ **权限控制**: 细粒度的RBAC权限系统

### 访问新功能
- `/banks` - 题库管理
- `/questions` - 题目管理
- `/subjects` - 学科管理
- `/ai` - AI控制台（需要权限）
- `/manager/dashboard` - 工作台（需要权限）
