## 一、需求分析与方案（小组共同）

### 1.1 项目背景

GraphTutor 是面向高校学生的智能学习平台。本小组开发 **微信小程序** 端，实现移动刷题、错题巩固、计划打卡与轻量社交，与 Web 端共用后端与数据库。

> **【截图位置：图1】** 登录页或我的页（登录后）。

### 1.2 可行性分析

- **技术**：WXML/WXSS/JS + JWT 鉴权，满足课程要求  
- **经济/操作**：免费开发工具；Tab + 菜单式「我的」页，易上手

## 三、项目实现（成员 B 负责部分）

### 3.1 登录与账号

1. 邮箱密码：`api.login` → 存 Token → `switchTab` 首页  
2. 微信：`wx.login` → `/api/auth/mp/login`  
3. `needsProfileCompletion` 时跳转 account-complete（link / register）  
4. 各 Tab 页 `onShow` 调用 `authHelper.ensureProfileComplete()`  

> **【截图位置：图7】** 登录页  
> **【截图位置：图8】** 完善账号页  
> **【截图位置：图9】** login.js 微信登录代码截图  
> **【截图位置：图10】** auth-helper.js 完善账号检测代码  

### 3.2 我的页与导航

1. user 页分区：学习中心 / 学习工具 / 学习分析 / 社交 / 个人  
2. 点击跳转 `navigateTo` 或 `switchTab` 至 A/B 各功能页  
3. 展示头像、角色、登录/退出  

> **【截图位置：图11】** 我的页全貌  
> **【截图位置：图12】** user.js 菜单配置代码截图

1. friends：列表 + 收到/发出请求，接受/拒绝调用 api-ext  
2. messages：会话列表，进入 chat 查看与发送文字消息  
3. 演示数据可通过服务端 seed 脚本导入好友与私信

### 3.4 笔记与社区

## 五、项目总结（成员 B 个人）

### 5.1 本人工作概述

负责 GraphTutor 小程序 **账号与社交** 模块：登录注册、微信登录、完善账号、我的页导航，以及好友、消息、笔记、社区、通知等。完成 `auth-helper.js` 与 `api-ext.js` 中社交相关封装，并统一登录注册 UI 样式。

### 5.2 优点与不足

- **优点**：多种登录方式；我的页入口清晰；好友/笔记可演示  
- **不足**：消息实时性可加强；部分页面 UI 仍可优化
