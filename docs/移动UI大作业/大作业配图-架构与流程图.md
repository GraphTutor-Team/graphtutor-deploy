### 图A-2 业务流程图（A 视角 · 学习主路径）

**报告位置：** 成员 A 报告「图3」

```mermaid
flowchart LR
  START((打开小程序))

  subgraph LOGIN["🟠 B：登录（前置）"]
    L1[登录/注册]
    L2{Token 有效?}
  end

  subgraph MAIN["🔵 A：学习主流程"]
    P1[练习 Tab / 配置页]
    P2[创建练习会话]
    P3[答题 session]
    P4[交卷 finish]
    P5[结果页 result]
    P6[错题自动入库]
    W1[错题 Tab 巩固]
    PL1[计划 Tab]
    PL2[今日复习 / 打卡]
    RP[复习计划 execute]
  end

  START --> L1 --> L2
  L2 -->|否| L1
  L2 -->|是| P1
  P1 --> P2 --> P3 --> P4 --> P5 --> P6
  P6 --> W1
  W1 --> P3
  L2 --> PL1 --> PL2
  L2 --> RP --> P3

  classDef stepA fill:#e3f2fd,stroke:#1565c0
  classDef stepB fill:#fff3e0,stroke:#ef6c00
  class P1,P2,P3,P4,P5,P6,W1,PL1,PL2,RP stepA
  class L1,L2 stepB
```

**讲解词（答辩）：**  
用户先经 B 模块完成登录获得 Token，再进入 A 负责的练习配置→创建会话→答题交卷→结果页；错题由后端自动写入错题本，可从错题 Tab、计划 Tab 或复习计划再次一键开练。

### 图B-2 业务流程图（登录分支重点标注 · B 视角）

**报告位置：** 成员 B 报告「图3」

```mermaid
flowchart TB
  START((用户打开小程序))

  START --> GATE{本地有 Token?}

  GATE -->|无| CHOICE{登录方式}
  CHOICE -->|邮箱密码| E1[输入邮箱密码]
  CHOICE -->|微信| W1[wx.login 取 code]
  E1 --> API1["POST /api/auth/login"]
  W1 --> API2["POST /api/auth/mp/login"]

  API1 --> SAVE[persistSession 存 token/userInfo]
  API2 --> SAVE

  SAVE --> NEED{needsProfileCompletion?}

  NEED -->|是| COMPLETE["完善账号 account-complete"]
  COMPLETE --> MODE{link / register}
  MODE --> API3["POST /api/auth/mp/complete-account"]
  API3 --> SAVE2[更新 token/userInfo]
  SAVE2 --> HOME

  NEED -->|否| HOME["switchTab 首页"]
  GATE -->|有| VALID{Token 有效?}
  VALID -->|否| REFRESH[refresh / 重新登录]
  REFRESH --> CHOICE
  VALID -->|是| HOME

  HOME --> USER[我的 Tab 菜单]
  USER --> F1[好友 / 消息 / 笔记 / 社区]
  USER --> A_TAB["🔵 跳转 A 模块 Tab/页"]

  subgraph HIGHLIGHT["🟠 B 负责（本图重点）"]
    CHOICE
    E1
    W1
    API1
    API2
    SAVE
    NEED
    COMPLETE
    MODE
    API3
  end

  classDef focusB fill:#fff3e0,stroke:#ef6c00,stroke-width:3px
  classDef focusA fill:#e3f2fd,stroke:#1565c0,stroke-width:1px
  class CHOICE,E1,W1,API1,API2,SAVE,NEED,COMPLETE,MODE,API3 focusB
  class HOME,USER,F1 focusB
  class A_TAB focusA
```

**讲解词（答辩）：**  
B 模块核心是登录分支：邮箱或微信获取 Token → 写入 Storage → 若需完善则进 account-complete 绑定邮箱 → 否则进首页；各页 `onShow` 通过 `ensureProfileComplete` 拦截未完善账号。

## 导出为报告截图的步骤

1. 打开 https://mermaid.live  
2. 复制上面对应成员的 `mermaid` 代码块（不含 \`\`\` 标记）  
3. 粘贴到左侧编辑器 → 右侧预览  
4. **Actions → PNG/SVG** 下载  
5. Word 中：**插入 → 图片**，图下方写「图2 功能模块结构图（A/B 分工）」等
