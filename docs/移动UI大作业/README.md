## 提交压缩包结构

```
大作业.zip
├── 项目源代码/                    ← miniprogram/ 一份
├── 项目演示视频.mp4               ← 一份（两人按第六节分工录）
├── 学号A-姓名A-大作业报告.pdf     ← 成员A 从 成员A-...md 导出
├── 学号A-姓名A-大作业评分表.xlsx
├── 学号B-姓名B-大作业报告.pdf     ← 成员B 从 成员B-...md 导出
└── 学号B-姓名B-大作业评分表.xlsx
```

---

## 操作步骤

1. 各自打开对应 **成员A/B** 的 MD 报告  
2. 填学号、姓名、班级、对方姓名  
3. 按附录补截图，改写 5.3 个人体会  
4. Word 粘贴 → 宋体五号 → 导出 PDF  
5. **评分表 CSV → xlsx**（已加 UTF-8 BOM，Excel 双击应能正常显示中文）  
   - 若仍乱码：Excel → **数据** → **从文本/CSV** → 选文件 → 文件原始格式选 **65001: Unicode (UTF-8)** → 加载  
   - 填好学号姓名后 **另存为 .xlsx** 再提交  
6. 合录演示视频（见各报告「第六节」时间分工）
