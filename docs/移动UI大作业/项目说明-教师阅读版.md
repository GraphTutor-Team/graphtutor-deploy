# GraphTutor 智能学习助手 — 项目说明

## 一、项目概述

**GraphTutor（图结构智能学习助手）** 是面向高校学生的在线刷题与学习管理平台。本项目包含 **微信小程序端**，并与 **Web 网站**、**Node.js 后端** 共用同一数据库：

- 同一账号可在 Web 与小程序登录，练习记录、错题、计划等数据同步
- 移动端支持刷题、考试、错题复习、学习计划打卡、好友与私信等流程

小程序将桌面端学习平台延伸至微信，便于随时练习、查阅错题并与同学交流。

## 二、应用场景

| 场景 | 实现方式 |
|------|----------|
| 移动刷题 | 底部 5 个 Tab 导航，数步内进入练习 |

| 协作交流 | 好友、私信、笔记、社区（与 Web 数据一致） |
| 多学科题库 | 数据结构、Java、计算机二级 MS/WPS、LeetCode 等 |

## 三、技术架构

```
┌─────────────────────┐
│  微信小程序          │  miniprogram/
│  微信开发者工具运行   │
└──────────┬──────────┘
           │ HTTP/HTTPS + JSON
           │ Authorization: Bearer <JWT>
           │ X-Client: miniprogram
           ▼
┌─────────────────────┐
│  Node.js 后端 API    │  server/  默认端口 5000
│  Express + MongoDB   │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐     ┌─────────────────────┐
│  MongoDB            │     │  Web 前端（React）   │
│  用户、题目、错题等  │◄───►│  client/            │
└─────────────────────┘     └─────────────────────┘
```

| 层次 | 技术 | 说明 |
|------|------|------|
| 小程序 | WXML / WXSS / JavaScript | 移动端界面与交互 |
| 后端 | Node.js 20 + Express | RESTful API |
| 数据库 | MongoDB | 持久化存储，与 Web 共用 |
| 缓存 | Redis | 会话与限流（Docker 部署时） |
| Web | React + Vite | 功能完整的浏览器端 |

## 六、运行与查看

### 6.1 微信小程序

1. 使用微信开发者工具打开 `miniprogram/` 目录  
2. 配置 `miniprogram/utils/config.js`：  
   - `BASE_URL`：后端地址（如 `http://106.55.99.208:5000`）  
   - `USE_VIRTUAL_LOGIN = true`：不连后端，仅浏览界面  
   - `USE_VIRTUAL_LOGIN = false`：连接后端，使用完整功能  
3. 开发者工具 → 详情 → 本地设置 → 勾选「不校验合法域名…」（本地预览）  
4. 编译运行，注册或登录后体验  

本地预览可使用测试号 AppID，无需单独申请发布。

### 6.2 后端与 Web

- API 健康检查：`GET /api/health`，返回 `"ok": true` 表示服务正常  
- Web 端：浏览器访问 `http://<服务器>:5000`，与小程序共用账号与数据

## 八、业务流程

```
注册 / 登录
    ↓
首页或练习 Tab → 选择题库与题量
    ↓
答题 → 交卷
    ↓
查看得分；错题进入错题本
    ↓
计划 Tab 打卡 / 执行复习计划
    ↓
好友与消息（可选）
    ↓
学习统计
```

同一账号在 Web 与小程序间数据一致。

---

## 九、项目特点

1. 前后端分离，小程序经 REST API 访问 MongoDB，非纯静态页面  
2. 覆盖练习 → 错题 → 复习 → 打卡的完整学习链路  
3. 请求统一封装（`utils/api.js`），含 JWT 刷新与异常处理  
4. 支持多种题型与题库（依赖后端导入）  
5. 集成好友、私信、笔记、社区等社交能力  
6. 提供 Docker 部署方案，可运行于云服务器

## 十、常见问题

| 问题 | 说明 |
|------|------|
| 无后端能否运行？ | 可设 `USE_VIRTUAL_LOGIN=true` 本地浏览界面 |
| 小程序与 Web 关系？ | 同一后端与数据库，小程序为移动入口 |
| 数据存储位置？ | MongoDB，含用户、题目、错题、消息等 |
| 首页推荐偶发较慢？ | 大题库下推荐接口可能延迟，已做兜底，不影响刷题与登录 |
| 成员贡献如何区分？ | 见第五节分工及各成员报告中的实现章节 |
