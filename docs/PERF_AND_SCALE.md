# 大数据量下的表现与优化

> 题目列表、知识图谱、统计图表在数据量较大时的接口与前端表现说明，以及已做的防护与建议。

---

## 一、题目列表（/questions）

### 接口

- **列表接口** `GET /api/v3/questions`：分页由 `questionQuery.js` 处理，**每页 limit 上限 100**（`validateInt(limit, { max: 100 })`）。  
- 题目总量 > 1 万时：单次请求仍只返回最多 100 条，**接口能扛住**。  
- **countDocuments(cond)**：在 10 万级且带复杂条件（如关键词 `$or` + 正则）时可能变慢，依赖索引。  
- 已有索引：`bankId`、`subjectCode`、`difficulty`、`type`、`tags`、`{ bankId, createdAt }`、`{ subjectCode, type }` 等；**全文/关键词搜索**无法完全走索引，大数据量下可考虑独立搜索服务或限制关键词长度。

### 前端

- 默认每页 20 条，表格只渲染当前页，**渲染量小，能扛住**。  
- **「导出全部」**：已改为**分页循环拉取**（每页 100 条，最多累计 5000 条），避免单次 `limit=10000` 被后端截断为 100 且请求过大。  
- 表格外层已包 `overflow-x-auto`，小屏可横向滚动。

### 结论与建议

- **列表 + 筛选 + 分页**：在题目量 > 1 万时，**接口和前端都能扛住**（分页 + limit 上限）。  
- 若总条数或 count 很慢：可对 `Question` 增加与常用筛选组合一致的复合索引，或对 count 做短期缓存。  
- 真正「导出全部」超过 5000 条时，可改用 `GET /api/v3/questions/export` 并配合服务端流式/分批导出。

## 二、知识图谱（/graph，节点列表）

### 接口

- **GET /graph/nodes**：原先**无 limit**，一次返回全部节点；节点多时响应体大、耗时长。  
- **已做**：增加 **limit 上限 2000**（可传 `?limit=xxx`，最大 2000），单次请求不再返回无限条。

### 前端

- 节点以**表格**逐行渲染；此前若一次加载数千节点，DOM 过多会卡。  
- **已做**：  
  - 仅渲染**当前页**节点（每页 50 条），总条数 > 50 时显示分页（上一页/下一页）。  
  - 序号与分页对应，避免一次渲染上千行。

### 结论与建议

- **节点 < 2000**：接口 + 前端分页下，**能扛住**。  
- **节点 > 2000**：当前只返回前 2000 个；若需「全部」可后续加服务端分页（page/skip），前端继续用分页或虚拟滚动。  
- 若将来做「力导向图」等可视化，建议用 Canvas/WebGL，并对可见区域或采样节点数做限制（如只展示前 500 个或按层级折叠）。

## 三、统计图表（学习分析 / Analytics）

### 接口

- **学习趋势** `GET /api/analytics/trend?days=xxx`：按天聚合，返回**每天一个点**，点数 = days。  
- **已做**：服务端对 **days 做上限 365**（`Math.min(365, Math.max(1, parseInt(days, 10) || 30))`），避免传 9999 导致数据量过大。  
- 知识点掌握度、学科/难度/题型分布：通常为聚合后的分类数，数据量不大。

### 前端

- 使用 **Recharts**（LineChart、BarChart、PieChart 等）。  
- **已做**：  
  - 学习趋势图对 **trendData 做采样**（`sampleData(trendData, 150)`），点数 > 150 时只取约 150 个点绘制，**保证渲染流畅**。  
  - 后端 days 已限制，前端即使用 365 天，采样后曲线仍可接受。

### 结论与建议

- **当前数据量**（按天聚合、days ≤ 365）：**接口和图表都能扛住**。  
- 若日后接口改为「按题/按次」等更细粒度，建议：  
  - 后端继续限制返回点数或聚合粒度；  
  - 前端对任意趋势类数据统一用 `sampleData(data, maxPoints)` 再交给 Recharts。

---

## 四、小结

| 场景           | 数据量 > 1 万 / 节点多 / 天数多时 | 已做防护 |
|----------------|-----------------------------------|----------|
| 题目列表       | 接口分页 limit≤100，前端只渲染当前页 | 导出全部改为分页拉取、最多 5000 条 |
| 知识图谱节点   | 接口曾一次全量返回                 | limit 上限 2000；前端表格分页每页 50 条 |
| 统计图表       | 趋势按天，点数=days               | days 上限 365；前端趋势采样 150 点 |

在以上防护下，**核心流程（练习、错题、打卡）以及列表、图谱、统计在大数据量下均可控、可扩展**。若后续有更高量级（如题目 10 万+、节点 5000+），可再增加：题目列表 count 缓存、图谱服务端分页、图表按需懒加载等。
